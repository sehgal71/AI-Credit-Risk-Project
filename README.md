# AI-Augmented Credit Risk Portfolio Analysis

## Overview
This project presents an end-to-end credit risk system for a UK retail loan portfolio. It combines SQL-based data processing, machine learning (logistic regression), and Power BI dashboards to analyse portfolio health and predict probability of default (PD).

## Objectives
- Analyse portfolio-level credit risk
- Identify high-risk customer segments
- Predict default probability using AI
- Compare rule-based vs model-driven risk segmentation
- Visualise insights for decision-making

## Tools & Technologies
- SQL (PostgreSQL)
- Python (Pandas, Scikit-learn)
- Power BI
- Excel

## Key Features
- Portfolio risk metrics (default rate, exposure, DPD analysis)
- Rule-based risk segmentation (Low / Medium / High)
- AI-based PD model (Logistic Regression)
- Feature importance analysis (risk drivers)
- AI vs rule-based classification comparison
- Interactive dashboard for risk monitoring

## Results
- Model ROC-AUC: ~0.73
- High Risk (AI): ~43% default rate
- Medium Risk (AI): ~27%
- Low Risk (AI): ~6%
- Strong alignment with real-world credit risk behaviour

## Conclusion
This project demonstrates how AI can enhance traditional credit risk analysis by improving precision in identifying high-risk customers and supporting proactive risk management decisions.

## Disclaimer
This project uses synthetic data for demonstration purposes. The model is intended for analytical and educational use only.
