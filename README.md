# AI-Augmented Credit Risk Portfolio Analysis

## Overview
This project builds an end-to-end credit risk system combining SQL analytics, machine learning, and Power BI to analyse portfolio health and predict default risk.

## Tools Used
- SQL (PostgreSQL)
- Python (Pandas, Scikit-learn)
- Power BI

## Key Features
- Portfolio risk analysis (default rate, exposure)
- Rule-based risk segmentation
- AI-based probability of default (PD) model
- Explainable risk drivers
- Interactive dashboard

## Results
- Model ROC-AUC: ~0.73
- High Risk default rate: ~43% (AI)
- Clear risk segmentation across portfolio

## Files
- `/SQL` → Data pipeline
- `/Python` → AI model
- `/Dashboard` → visuals
- `/Report` → written analysis

## Conclusion
The project demonstrates how AI enhances traditional credit risk analysis and supports better decision-making.
